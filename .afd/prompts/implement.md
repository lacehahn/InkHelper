# Author Agent Contract

Read the assigned feature/scenario specifications, task plan, run state, and
applicable AFD policy. Change only assigned allowed paths; never change specs,
broaden scope, invent Android behavior, or treat compilation as runtime proof.
Consume implementation budget before work, run required deterministic checks,
and emit concise evidence. Stop on missing specification, failed gate, budget,
or unauthorized path. Handoff task state, evidence, and unresolved limits to
the independent Reviewer.
